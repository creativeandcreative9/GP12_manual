# 着せかえ工房 使用手引書

Unity のエディタ拡張「着せかえ工房」（ほかのアバター用の衣装を、自分のアバターに着せる道具）の使用手引書です。

- 手引書: `着せかえ工房使用手引書.html`（CSS・JS 入りの 1 ファイル。ブラウザで開いて読む）
- `index.html` は、手引書へ移動するだけの入口です。
- 画像は `images/` に置きます。HTML からは `images/…` の相対パスで参照します。

## 作り方（作業メモ。公開の前に、この節から下を消す）

### 正本
- **この HTML が正本です。直接編集します。** 古い下書きから作り直して上書きしません。直す前に `git fetch` します。
- 章の ID（`ch-…`）とクラス名（`zukan-card` など）は変えません。目次・リンク・検査が使います。
- 章を足したら、`nav.toc` と、表紙の一覧の両方に足します。

### 画像
- `images/<章>_<連番>_<内容>.png`（例 `02_01_import_window.png`、`zukan_01_three_inputs.png`）。幅は 640〜1600px。
- 画像は完成してからコミットします（撮り直しで履歴が太るため）。
- **購入した素材のデータ（メッシュ・テクスチャ・Prefab・マテリアル・unitypackage・zip）は、このリポジトリに入れません。入れるのは、規約が許す画像（PNG）だけです。**
- 素材の名前・作者名・ライセンス表記は、「クレジット」の章だけに書きます。本文・alt・画像の名前には出しません。

### 検査
検査と採点のスクリプトは、製品のリポジトリの `tools/manual/` にあります（このリポジトリには置きません）。
```
python3 -I <製品のリポジトリ>/tools/manual/manual_check.py 着せかえ工房使用手引書.html --score
python3 -I <製品のリポジトリ>/tools/manual/manual_check.py 着せかえ工房使用手引書.html --final --ui-audit <ui-audit.json>
```
使い方は `tools/manual/README.md` を見ます。`--final` は公開前の検査です。違反が 0 件になってから公開します。

### 空いている印（`grep -n '{{' 着せかえ工房使用手引書.html` で探す）
| 印 | どこ | いつ決めるか |
|---|---|---|
| `{{VERSION}}` | 表紙の「版」と「入れ方」の版（例 1.0.0） | 公開の直前（製品の版と合わせる） |
| `{{DATE}}` | 表紙の「日付」（YYYY-MM-DD） | 公開の直前 |
| `{{SHOP}}` | BOOTH のショップ名 | 公開の直前 |
| `{{BOOTH_URL}}` | BOOTH の商品ページの URL（「はじめに」と「入れ方」に入れる） | 公開の直前 |
| `{{PRICE}}` | 価格 | 公開の直前 |
| `TODO-NAME` | 「入れ方」の unitypackage の名前。メニューの道すじ・Add Component の道すじ | 画面の名前が確定したら |

`{{BOOTH_URL}}` は「はじめに」と「入れ方」のリンクの中にあります。`{{SHOP}}`・`{{PRICE}}` は、どこにも使っていません（使うなら表紙へ足します）。
