# きがえ工房 使用手引書

Unity のエディタ拡張「きがえ工房」（ほかのアバター用の衣装を、自分のアバターに着せる道具）の使用手引書です。

- 手引書: `きがえ工房使用手引書.html`（CSS・JS 入りの 1 ファイル。ブラウザで開いて読む）
- `index.html` は、手引書へ移動するだけの入口です。
- 画像は `images/` に置きます。HTML からは `images/…` の相対パスで参照します。

本文は、1組無料体験と共通Proキーに対応する版の案内です。4つの強み、3ステップの導入、無料版とPro、仕上げのレシピ、画面・FAQの5層で構成しています。詳細手順は折りたたみで開き、従来のアンカーから直接移動できます。

作例は指定素材（MANUKA・Tsubomi・ゆうこ（Yuko）、HINOshop・Chiyo_ya・MANUKA初期衣装）を使用します。画像は撮影時点の表示例です。素材の帰属は本文のクレジットに記載しています。
